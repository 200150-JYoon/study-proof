# 사이트 설계도(PRD) — 우리 아들 매일 공부 인증 사이트

작성일: 2026-10-26 · 이 문서는 사이트를 고칠 때마다 다시 보는 기준이다.

## 1. 한 줄 정의
고2 아들이 매일 공부한 과목과 "오늘 한 것" 한 줄을 인증하면 연속 기록 불꽃이 올라가고, 7일을 채우면 치킨(먹고 싶은 것)을 받는 공부 인증 사이트.

## 2. 사용하는 사람
- 누가: 고2 아들 (화면에서 부를 이름: 성현)
- 어디서 들어오나: 엄마가 매일 카톡으로 보내는 링크를 눌러서 (휴대폰 화면 기준으로 만든다)

## 3. 아들이 들어오자마자 보고 싶은 것
1. 지금 연속 며칠째인지 (불꽃 🔥 + 숫자)
2. 치킨까지 앞으로 며칠 남았는지
3. 오늘 인증 남기는 칸 (이미 했으면 "오늘 완료")

## 4. 믿게 할 증거
- 해당 없음 (가족용 사이트). 대신 "7일 → 치킨" 엄마의 약속이 화면에 그대로 적혀 있는 것이 이 역할을 한다.

## 5. 누르게 할 버튼 하나
- 버튼 이름: 오늘 공부 인증 (가칭)
- 누르면: 오늘 공부한 과목 + 한 줄이 저장되고, 연속 기록 불꽃이 1 올라가고, 치킨 칸이 한 칸 찬다
- 인증은 하루에 한 번. 저장하면 그날은 칸이 잠기고, 다음 날 다시 열린다

## 6. 페이지 구성 (위에서 아래로, 1장)
1. 첫 화면 — "성현" 이름 인사 + 연속 기록 불꽃(🔥 N일째)
2. 보상 칸 — 연속 7칸 중 몇 칸 찼는지 + "연속 7일 채우면 치킨(먹고 싶은 것)". 하루 빠지면 0칸, 치킨 받으면 다시 0칸
3. 오늘 공부 인증 — 과목 고르기 + 오늘 한 것 한 줄 + 버튼
4. 지난 인증 기록 — 날짜·과목·한 줄, 새 기록이 맨 위

## 7. 인증 칸에서 받을 것
- 오늘 공부한 과목 (아래 과목 중에서 고르기, 여러 개 가능)
- 오늘 한 것 한 줄 (예: 수학 문제집 3쪽)
- 이름·연락처 등 개인정보는 받지 않는다

## 8. 정확해야 하는 사실 (사용자가 말한 그대로)
- 과목: 국어, 수학, 영어, 탐구(사회·과학), 기타
- 보상: 7일 → 치킨·먹고 싶은 것
- 7일 기준: 연속 7일 (하루라도 빠지면 치킨 칸도 0부터 다시)
- 보상을 받은 뒤: 치킨 칸은 다시 0부터 시작
- 아들 이름: 성현
- 들어오는 방법: 엄마가 매일 카톡 링크를 보낸다

## 9. 이번에 넣지 않을 것
- 엄마 휴대폰에서 기록 보기 — 온라인 저장(Supabase) + 엄마 전용 페이지(/admin). 이번엔 기록이 아들 휴대폰에만 남고, 엄마는 아들 화면을 같이 보며 확인한다
- 공부 시간 타이머
- 오늘 할 일 체크리스트
- 로그인·회원가입 (링크만 누르면 바로 들어온다)
- 알림 보내기 (메일·카톡 알림)
- 사진 올리기 (공부 인증 사진)
- 홈 화면 아이콘(앱처럼 설치하기)

## 10. 첫 화면 한 문장 후보
1. "🔥 [N]일째. 오늘도 불 꺼뜨리지 말자"
2. "치킨까지 [n]일 남음 🍗"
3. "오늘 한 줄만 남기면 끝"

## 12. 만드는 방법 (클로드가 끝까지 만들 때 기준)
- 분위기: 게임처럼 다크한 (어두운 배경에 레벨·불꽃이 빛나는 느낌, 고2 남자아이가 유치하다고 느끼지 않게) · 참고 디자인: 없음 — 클로드가 정함
- 기록 저장: 온라인 저장 아니요 → 아들 휴대폰 브라우저에만 저장(localStorage)
- 회원가입: 이번엔 아니요
- 폴더: C:\site-study (기존 시험기간 응원 사이트 C:\site 와 따로)
- 배포: GitHub 공개 저장소 + Vercel

## 13. 만드는 순서 (클로드가 처음부터 끝까지 한 번에)
1. 스타일(색·글꼴)을 분위기에 맞게 정하고 첫 화면부터 만든다
2. 연속 기록 불꽃 · 7칸 보상 · 하루 1번 인증 · 지난 기록 목록을 만든다
3. GitHub 공개 저장소에 올리고 Vercel로 배포해 내 주소를 만든다
4. 다 만든 뒤 한 번에 보고: 내 사이트 주소 · 확인 방법 · 엄마가 할 일(카톡으로 링크 보내기)
- 사용자가 직접 할 일(이때만 멈춤): 로그인, 결제
